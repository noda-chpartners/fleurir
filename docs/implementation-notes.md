# Fleurir LP 実装・運用メモ

## 実装内容

- Astroの静的LP。店舗情報・料金・メニューは `src/data/shop.ts` に集約。
- 生成した横長／縦長ヒーローと、提供された実店舗写真を採用。
- ヒーロー直下に人物・お祝い・店内のフォトコラージュを配置。料金と席数はソファ席写真と一体化。人気メニューは料理イメージ3点を中心に構成。
- 元画像7点（人物、お祝い、店内2点、ロゴ、メニューポスター、LINE QR）を採用。メニューポスターはdialogで拡大表示でき、Escape・閉じるボタンとフォーカス復帰に対応。
- Instagramを写真コラージュ下へ統合。アクセス、1階の正式サイト、電話とLINEの導線を実装。
- GSAPとScrollTriggerで文字・写真の表示とPCの緩やかなパララックスを実装。
- LenisはGSAP tickerと同期。タッチの慣性模倣は無効。prefers-reduced-motionではLenisと動きの処理を初期化しない。
- スマートフォンは電話と地図への固定導線。Googleマップ・Instagram・1階サイトは新しいタブで開く。
- 実店舗写真の階数は未確認のため、個々の写真を特定階に割り当てていない。
- 生成元画像は `src/assets/generated/`、プロンプトは `docs/image-prompts.md` と `docs/menu-image-prompts.md` に保存。料理画像はイメージである旨をページに明記。

## 公開時

本番URLが決まったらAstroの `site` を設定し、canonicalと絶対URLのOG画像を設定する。現段階はローカル制作物であり、ホスティングへの公開操作は行っていない。

WebフォントはGoogle Fontsを使用。取得できない場合は端末の日本語明朝・ゴシックにフォールバックする。

## 起動とビルド

```powershell
npm run dev -- --background
npm run astro -- dev status
npm run astro -- dev logs
npm run astro -- dev stop
npm run build
```

ローカルプレビューURLは起動時の出力を使う。使用中のポートがある場合、4321以外になる。環境によってバックグラウンドプロセスが親セッション終了と同時に停止する場合は、開発ターミナルで起動・管理する。
