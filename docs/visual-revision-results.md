## 構成の変更

- ヒーローの次に人物と実店舗の写真が見える順番へ変更。
- 料金、店内、席数を1ブロックへ集約。
- 人気メニューを大きな料理画像1点と補助画像2点で紹介。
- Instagramの独立した長い紹介を写真ブロック下の短い案内へ統合。
- 連絡先を元のロゴ、電話、LINE QRとリンクで構成。
- 既存の電話、地図、Instagram、1階正式サイトへのリンクを維持。

## 補助画像とメニュー表示

新しい料理画像は実物を撮影したものではないため、メニュー内にイメージ表記を掲載。価格・器・盛り付け等の新しい実店舗情報としては扱っていない。

メニューポスターは参考資料として表示し、内容・料金は店頭確認の案内を添えた。画像内の求人・割引情報は新たに掲載していない。

LINE URLは元のQRコードをローカルで読み取った結果を使用。QRはPNGで出力。予約受付の可否は断定していない。

## 操作の確認

- メニューポスターの拡大、閉じるボタン、Escapeでの終了、元ボタンへのフォーカス復帰を確認。
- モーダル表示中の背景スクロールを止め、閉じた後に復帰。
- PC・スマートフォンの画像表示と横方向のはみ出しを確認。
- 通常の表示状態でブラウザーのconsole error/warnなし。
- 360・390・768・1440px相当で横方向のはみ出しなし。
- 最終 `npm run build` 成功。ビルドしたローカル画像・リンク先・ページ内アンカーの存在を検証。
- 出力された180pxのLINE QR画像も再度読み取り、ボタンと同じURLへ対応することを検証。
- 完成画面は `docs/previews/revised-welcome.jpg`、`revised-menu.jpg`、`revised-full-desktop.jpg` に保存。

コードはWelcome、Rates、Menu、Contactコンポーネントへ分割。表示用画像はWebPに最適化し、元画像は保持している。生成プロンプトは `docs/menu-image-prompts.md` に記録。
